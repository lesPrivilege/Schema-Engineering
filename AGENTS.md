# Schema Engineering · Paper workspace

This repository maintains the Canonical, Practice, Practice Index and paper build/release tooling. Read README.md and CONTRIBUTING.md before editing. Preserve existing paper drafts; a local candidate version is not a published release.

CourtWork implementation, design assignments, runtime work and acceptance now live in the sole persistent sibling `../Courtwork` checkout. For a CourtWork task continued in this SE project space, explicitly set the command working directory to that checkout, read its AGENTS.md and engineering/current.md, then the relevant contract/evidence. Keep product code and engineering tickets there.

The legacy `../Courtwork-legacy-frozen` working tree is a frozen reference. Recall only an explicitly relevant frozen SHA/path; do not treat its old instructions or implementation as current authority. Existing task history remains available in this project space, while the current CourtWork repository files provide the durable handoff. The old `../Courtwork-fresh` checkout is also frozen and must not be used for continued development. Read the actual Git branch/ref rather than registering Fresh as a separate development line.

Paper feedback from engineering belongs in the Practice Index only when it supports a generalizable observation, with a fixed CourtWork commit and evidence link. Do not mirror product status or open a second revision ledger here.
